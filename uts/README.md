# Petunjuk Penggunaan Program
1. Pastikan menggunakan versi python terbaru, install library opencv dan numpy dengan perintah “pip install opencv-python numpy”
2. Buat direktori untuk program + video
3. Install program .py dan source video dari link: https://drive.google.com/drive/folders/1K5FumaZMBn15Cavui-MWPK744b694xpz?usp=sharing
4. Buka terminal pada direktroi project dan jalankan perintah “python main.py” 
5. Program akan menampilkan jendela hasil video pemrosesan
