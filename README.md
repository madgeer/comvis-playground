# Computer Vision Playground

Kumpulan demo OpenCV, satu folder = satu materi.

## Struktur

- `assets/` — input shared
- `01-img-operation/` — addition, substraction, invert
- `02-img-filtering/` — mean filter / konvolusi
- `03-edge-detection/` — Canny
- `04-harris-corner/` — Harris corner
- `05-img-matching/` — template matching

Tiap folder berisi `README.md` (penjelasan) + `main.py` + `output/`.

## Cara pakai

```bash
pip install -r requirements.txt
python 01-img-operation/main.py
python 02-img-filtering/main.py
python 03-edge-detection/main.py
python 04-harris-corner/main.py
python 05-img-matching/main.py
```
